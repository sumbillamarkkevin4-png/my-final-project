# NEXORA GAMING
### Gaming Accessories Store Management System

**NEXORA GAMING** is a console-based shopping and inventory management system developed using C++. It allows customers to browse gaming accessories, search products, manage shopping carts, and checkout orders. It also provides an administrator panel for managing inventory and monitoring sales.

## Features

### Customer Section
- View all available products
- Search products by name or ID
- Filter products by brand and category
- Sort products by price
- Add products to shopping cart
- View cart items (forward and backward)
- Undo the last cart addition
- Checkout and generate receipts

### Administrator Panel
- View product inventory
- Add new products
- Update product information
- Delete products
- Search products by ID
- Display low-stock products
- View completed order history
- View latest completed order
- Display product IDs using Binary Search Tree
- Demonstrate binary search comparisons
- View best-selling products leaderboard
- Check balanced parentheses

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Compile the C++ source code:

```bash
g++ main.cpp -o nexora
```

5. Run the program:

```bash
.\nexora.exe
```
